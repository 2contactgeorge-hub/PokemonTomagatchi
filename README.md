# PokéPal HG v10 — World Cycle

A modular HeartGold-inspired virtual-pet web game for GitHub Pages.

## v10 changes
- Rebuilt route/outdoor scene, Poké Mart interior, Pokémon Center interior, and battle backdrop.
- Live device clock with day/evening/night visual states.
- Permanent mortality is always enabled and cannot be disabled.
- Fullness continues to fall while the app is closed; prolonged starvation damages health and can permanently kill the Pokémon.
- Sleep persists in real time. A full sleep lasts up to 8 real hours and naturally restores energy.
- Watching Training Discs darkens the bedroom and turns the TV screen blue.
- Pokémon Center is a real destination with free healing/rest.
- Walking to either the Poké Mart or Pokémon Center has a chance of a random wild encounter before arrival.
- Existing v9 saves migrate automatically.

## GitHub Pages
Upload the contents of this folder to the repository root and enable Pages from the `main` branch / root.
